# Project Memory & Studio Generator Engine (GEMINI.md)

> **АВТОМАТИЧЕСКИЙ ТРИГГЕР НА ССЫЛКИ (Яндекс Карты / 2ГИС / Сайты студий):**
> Когда пользователь присылает в чат ссылку на Яндекс Карты (`yandex.ru/maps...`, `yandex.com/maps...`), 2ГИС или просто пишет название и город детейлинг-студии без дополнительных инструкций, ты **ОБЯЗАН** автоматически выполнить пайплайн создания нового пресета:

## Пайплайн создания студии

### 1. Извлечь данные
- Получить URL или ID организации.
- Запросить веб-страницу организации. Если Яндекс Карты выдают SmartCaptcha или пустую страницу — **НЕ ОСТАНАВЛИВАТЬСЯ** и не запрашивать ручной ввод капчи. Извлечь ID/название организации из URL и выполнить веб-поиск (2ГИС, VK, агрегаторы, сайт студии).
- Собрать обязательные данные:
  - Название студии (`name`, `shortName`).
  - Адрес и город филиала (`address`, `city`).
  - Телефон (`phone`) и график работы (`workingHoursText`).
  - Координаты (`coordinates: { lat, lng }`).
  - Рейтинг и награды (например, «Хорошее место 2026», рейтинг `4.9`–`5.0`).
  - Логотип и ключевые фото интерьера/боксов/работ.

### 2. Обработать логотип и ассеты
- Скачать официальный логотип студии в `public/logos/<slug>.png`.
- Скачать ключевые фото работ/боксов в `public/images/<slug>/`.
- Если логотип растровый отсутствует — настроить автогенерацию стильной SVG-монограммы через `generateSvgLogoDataUri`.

### 3. Сформировать прайс (`priceByClass`)
- Разложить цены по 3 классам автомобилей:
  - `class_1_sedan` — базовый седан;
  - `class_2_suv` — кроссовер / компактный SUV (+20%, округление до 500 ₽);
  - `class_3_xl` — полноразмерный внедорожник / минивэн (+40%, округление до 500 ₽).
- Если в источнике указана только одна базовая цена — использовать её для 1 класса, а для 2 и 3 классов рассчитать по формуле выше.
- Если прайс не найден — подставить реалистичные региональные бенчмарки (Москва/СПб — премиум, регионы РФ — средний чек).
- **Критическое правило:** обязательно сохранить минимум одну услугу с `priceType: 'inspection'` («После осмотра — слот 30 мин, 0 ₽»), одну `fixed` и одну `from`.
- Оформить блок допродажи `upsellOffer` со скидкой.

### 4. Зарегистрировать пресет
1. Создать файл `src/studios/presets/<slug>.ts`.
2. Добавить его в реестр `src/studios/index.ts` (`studiosRegistry`).
3. Создать запись `tenants/<slug>/business.json` и зарегистрировать в `src/lib/db-mock.ts`.
4. Добавить маршрут в `scripts/deploy-gh-pages.mjs`.
5. Проверить проект через `npm run build` и `npm test`.
6. Выдать пользователю готовую ссылку для просмотра:
   - Локально: `http://localhost:5173/?studio=<slug>`
   - На хостинге: `https://inyakindmitry1-wq.github.io/dete-booking/?studio=<slug>`
