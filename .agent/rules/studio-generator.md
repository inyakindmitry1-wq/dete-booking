# Studio Generator & White-Label Rebranding Engine Rule

> **АВТОМАТИЧЕСКИЙ ТРИГГЕР НА ССЫЛКИ (Яндекс Карты / 2ГИС / Сайты студий):**
> Когда пользователь присылает в чат ссылку на Яндекс Карты (`yandex.ru/maps...`, `yandex.com/maps...`), 2ГИС или просто пишет название и город детейлинг-студии без дополнительных инструкций, ты **ОБЯЗАН** автоматически выполнить пайплайн создания нового пресета:

## Пайплайн создания студии

### 1. Извлечь реальные данные
- Получить URL или ID организации.
- Спарсить или запросить через fetch/поиск веб-страницу организации.
- Если Яндекс Карты отдают SmartCaptcha или пустую страницу — **НЕ ОСТАНАВЛИВАТЬСЯ** и не запрашивать ручной ввод. Извлечь ID/название организации из URL и запросить веб-поиск (2ГИС, VK, агрегаторы, сайт студии).
- Собрать обязательные поля:
  - Точное официальное название студии (`name`, `shortName`).
  - Город и фактический адрес филиала (`address`, `city`).
  - Номер телефона (`phone`) и график работы (`workingHoursText`).
  - Координаты (`coordinates: { lat, lng }`).
  - Рейтинг и награды (например, «Хорошее место 2026», рейтинг `4.9`–`5.0`).
  - Прямой URL логотипа и ключевых фотографий боксов/работ.

### 2. Обработать логотип и медиа
- Скачать официальный логотип студии в `public/logos/<slug>.png`.
- Скачать ключевые фото работ/боксов в `public/images/<slug>/` (например, `hero.jpg`, `bay-1.jpg`).
- Если логотип растровый отсутствует — сгенерировать стильную SVG-монограмму с первыми буквами названия в акцентном цвете на темном фоне `#09090b`.

### 3. Сформировать матрицу услуг и цен (3 класса авто)
- Разложить услуги и цены по 3 классам автомобилей:
  - `class_1_sedan` — базовый седан;
  - `class_2_suv` — кроссовер / компактный SUV (+20%, округление до 500 ₽);
  - `class_3_xl` — полноразмерный внедорожник / минивэн (+40%, округление до 500 ₽).
- Если в источнике указана только одна цена — использовать её для 1 класса, а для 2 и 3 классов рассчитать по формуле выше.
- Если прайс не найден — применить региональный бенчмарк:
  - Москва/СПб: мойка ~3500 ₽, полировка ~28000 ₽, керамика ~45000 ₽, PPF ~240000 ₽.
  - Регионы РФ: мойка ~2000 ₽, полировка ~18000 ₽, керамика ~22000 ₽, PPF ~160000 ₽.
- **Обязательные типы цен (PriceType):**
  - Минимум 1 услуга с `priceType: 'inspection'` («Осмотр и диагностика ЛКП — 30 мин, 0 ₽»);
  - Минимум 1 услуга с `priceType: 'fixed'`;
  - Минимум 1 услуга с `priceType: 'from'`.
- Оформить карточку `upsellOffer` (допродажа со скидкой, например «Антидождь» или керамика дисков).

### 4. Зарегистрировать пресет в коде
1. Создать файл пресета `src/studios/presets/<slug>.ts`, импортирующий `StudioPreset` из `../types`.
2. Зарегистрировать созданный пресет в реестре `src/studios/index.ts`:
   - Импортировать `<slug>Preset` из `./presets/<slug>`.
   - Добавить в `studiosRegistry: Record<string, StudioPreset>`.
3. Создать запись тенанта в `tenants/<slug>/business.json` и подключить в `src/lib/db-mock.ts`.
4. Добавить путь в `scripts/deploy-gh-pages.mjs` (`s/<slug>`, `s/<slug>/owner`).
5. Проверить проект:
   - `npm run typecheck`
   - `npm test`
   - `npm run build`
6. Выдать пользователю готовую ссылку для просмотра:
   - Локально: `http://localhost:5173/?studio=<slug>`
   - На постоянном хостинге: `https://inyakindmitry1-wq.github.io/dete-booking/?studio=<slug>`
